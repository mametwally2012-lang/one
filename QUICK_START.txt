🎨 FireBrush Studio - دليل البدء السريع
════════════════════════════════════════════

📥 الخطوة 1: التحميل
─────────────────
git clone https://github.com/mametwally2012-lang/one.git
cd one

🔧 الخطوة 2: التثبيت
──────────────────
Windows:  اضغط مرتين على RUN_ME.bat
Mac/Linux: bash RUN_ME.sh

⚡ الخطوة 3: الاستمتاع!
──────────────────
ستظهر نافذة بها:
  🔵 كرة زرقاء (النموذج الافتراضي)
  🔳 شبكة أرضية رمادية
  📊 قائمة على الأعلى

🎮 ابدأ النحت:
──────────────
  Alt + الماوس اليسار  → دوّر الكاميرا
  الماوس اليسار        → انحت
  Space              → تمويه
  G                  → أداة Grab
  Ctrl+Z             → تراجع
  ESC                → خروج

💡 تلميحات:
──────────
  • جرب القائمة: "📁 ملف" → "📂 استيراد"
  • اختر أداة من: "🎨 الفرش"
  • غيّر الإعدادات في: "⚙️ الإعدادات"

❓ مشاكل؟
──────────
  ✋ لا نافذة؟ → تأكد من GPU حديث
  ❌ خطأ مكتبات؟ → الـ scripts تثبتها تلقائياً
  🐌 بطيء؟ → قلّل حجم النموذج
