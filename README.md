# 🎨 FireBrush Studio

محرر نحت **بسيط وقوي** - بدون الفوضى!

## ✨ الفكرة الأساسية

- **بسيط أولاً**: واجهة نظيفة وواضحة
- **5 فرش فقط**: ما تحتاجه بالفعل
- **قوي حقاً**: GPU Compute Shaders
- **خالي من الفوضى**: لا ألف خيار مثل Blender!

## 🚀 التشغيل السريع

### **Windows** 🪟
```bash
# 1️⃣ انسخ المجلد
git clone https://github.com/mametwally2012-lang/one.git
cd one

# 2️⃣ اضغط مرتين على:
RUN_ME.bat
```

### **Mac/Linux** 🍎🐧
```bash
# 1️⃣ انسخ المجلد
git clone https://github.com/mametwally2012-lang/one.git
cd one

# 2️⃣ شغّل:
bash RUN_ME.sh

# أو مباشرة:
python3 firebrush.py
```

### **على VSCode**
1. افتح المجلد في VSCode
2. اضغط `Ctrl+\`` لفتح Terminal
3. اكتب: `python firebrush.py`
4. اضغط Enter

**آن الأوان لترى سحر النحت!** ✨

## 🤖 دعم أندرويد (لمسة و gestes)

يمكنك تشغيل FireBrush على أندرويد باستخدام Python for Android / Chaquopy أو إنشاء APK مخصص.

### الإيماءات المدعومة:
- رفع اصبع واحد والتحريك على الخلفية → **دوران**
- رفع اصبع واحد والتحريك على المجسم → **نحت**
- سحبتين في نفس الاتجاه → **تدوير المشهد (Pan)**
- سحبتين نحو بعضهما → **تكبير**
- سحبتين بعيداً عن بعضهما → **تصغير**

> يتم اكتشاف اللمسات عبر واجهات مخصصة تحتاج إلى ربط بواسطة JNI أو مكتبة طرف ثالث.

### تحميل التطبيق للأندرويد
- قم بتنزيل APK جاهز من الملف `FireBrush.apk` في المجلد.
- ثبّت الملف على جهازك وابدأ النحت!

## 🆘 المشاكل الشائعة

### ❌ "ModuleNotFoundError: No module named 'glfw'"
```bash
pip install glfw
```

### ❌ "GLFW error: X11"
**على Linux**: تثبيت المكتبات:
```bash
sudo apt-get install libglfw3-dev libx11-dev
```

### ❌ "OpenGL error"
تأكد من:
- 🎮 وجود كرت شاشة GPU حديث
- 🔧 تحديث drivers (NVIDIA/AMD/Intel)

### ❌ "Window won't open"
جرب:
```bash
python firebrush.py --force-software  # إن وُجد
```
